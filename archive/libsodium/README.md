## Libsodium implementation

### This is a typescript implementation meant to run in web and node

It was built using the [libsodium-wrappers](https://github.com/jedisct1/libsodium.js/blob/master/package-libsodium-wrappers.json) package.

It was the original implementation of this project and is being archived for future reference.

Some old code is left commented and some partially modified for function.
